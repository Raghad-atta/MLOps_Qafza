 # MLOps Engineering Training Program
 This is a training program offered by Qafza Tech, a Jordanian training academy specializing in data science, data analysis, and artificial intelligence. It offers accredited certificates based on a practical training approach from scratch to job. This training specializes in managing and automating the entire lifecycle of machine learning models, from data preparation and model development to training, evaluation, deployment, monitoring, and continuous updating.

 ## Training Technologies
 - Python 
 - Pandas & NumPy  
 - Scikit-learn 
 - PostgreSQL 
 - Git & GitHub 
 - Docker  
 - MLflow 
 - Jupyter Notebook 
 - CI/CD Tools

 ## project: Brazilian E-Commerce Public Dataset by Olist
 It is a real and anonymous dataset containing approximately e-commerce orders in Brazil during the period from 2016 to 2018. The data includes multiple information about orders, customers, products, prices, payment methods, shipping, and customer reviews, making it suitable for analyzing e-commerce processes and building data analytics and machine learning projects.
